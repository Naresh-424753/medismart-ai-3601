Closed loopReading → validated and stored → rule/ML check → alert to patient and doctor → doctor reviews and prescribes → reminders and follow-ups.
Human in the loopScanned prescriptions become reminders only after a doctor or pharmacist verifies. Risk and image outputs are screening support, not diagnoses.
DeploymentDocker Compose: API (:8000), React (:5173), MongoDB. Modular routers can be split into separate services behind a gateway as load grows.
Not a hospital-grade systemNo FHIR/HL7 interface or PACS integration is built; HIPAA/DPDP compliance needs a formal review.
